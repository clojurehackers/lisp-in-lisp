Cons, car, cdr, quote, cond, lambda… Com um pequeno conjunto de primitivas, o LISP nos permite construir funções que vão muito além das operações básicas. Nesta apresentação, vamos seguir os passos de [The Roots of Lisp](https://paulgraham.com/rootsoflisp.html) e implementar uma versão enxuta de uma linguagem de domínio, explorando como suas próprias primitivas dão origem a um interpretador capaz de executar programas escritos em LISP.
